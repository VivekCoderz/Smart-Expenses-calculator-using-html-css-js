# Smart Expenses Calculator

A small HTML/CSS/JavaScript page. You enter your total income and total expenses, and it shows:

- Remaining balance (Rs)
- Saving percentage
- Expenses percentage

If expenses are higher than income, it shows how much more you need to earn.

## Run
Open `index.html` in a browser. There is no build step and no dependencies.

## Files
- `index.html`: the form
- `style.css`: styles
- `script.js`: calculation logic
